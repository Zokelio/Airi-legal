# Airi — Privacy Policy

**Last Updated:** October 23, 2026

## 1. Introduction

Welcome to Airi!

Airi ("the Bot", "we", "our", or "us") is a multipurpose Discord bot designed to provide moderation, music, utility, AFK, welcome, and community management features.

This Privacy Policy explains how Airi collects, processes, stores, uses, and protects information when users interact with the Bot.

By using Airi, you acknowledge the data practices described in this Privacy Policy.

## 2. Information We Collect

Airi may collect or process the following information, depending on the features being used.

### 2.1 Discord User Information

- Discord user IDs
- Usernames and display names
- Public profile information, including avatars
- Server membership information
- Information necessary for moderation and community features

### 2.2 Discord Server Information

- Server IDs and names
- Channel IDs
- Role IDs
- Server configuration and feature settings
- Information required for welcome messages, moderation, and other server utilities

### 2.3 Message Information

Airi may access and process message content when necessary to provide features such as:

- Traditional prefix commands
- AFK detection and notifications
- Automated responses
- Message-based moderation
- Other configured message-triggered functionality

Message content is processed to provide the relevant functionality.

Airi may store message-related information when required for specific features, including moderation records, AFK messages, and ticket transcripts.

### 2.4 Feature-Specific Data

Depending on the enabled features, Airi may store:

- AFK status and associated messages
- Moderation warnings and records
- Ticket configurations and support records
- Server-specific preferences
- Command usage information
- Economy and leveling information
- Other data necessary to provide the Bot's features

## 3. How We Use Information

Airi uses collected information to:

1. Execute commands and provide requested functionality.
2. Maintain server configurations and preferences.
3. Deliver welcome messages and AFK notifications.
4. Support moderation and server management.
5. Operate ticket and community features.
6. Maintain economy and leveling systems.
7. Diagnose technical issues and improve reliability.
8. Prevent abuse and unauthorized use of the Bot.

Airi does not use Discord API data for unrelated advertising or sell personal information.

## 4. Data Storage

Airi uses MongoDB to store information necessary for its operation.

Stored information may include Discord identifiers, server configurations, moderation records, AFK information, economy balances, and other feature-specific data.

Data may be stored outside Discord through the Bot's database and hosting infrastructure.

Access to stored information is restricted to authorized operators and relevant infrastructure providers.

## 5. Data Retention

Airi retains information for as long as reasonably necessary to provide its features, maintain server functionality, or satisfy applicable legal obligations.

### 5.1 AFK Records

AFK status information and associated messages are retained until the user's AFK status is cleared or the record is otherwise deleted.

### 5.2 Moderation Records

Warnings and other moderation records may be retained until removed by an authorized server administrator or deleted following a valid data deletion request, subject to applicable legal obligations.

### 5.3 Ticket Data

Ticket configurations are retained while needed for the relevant server's ticket system.

Ticket transcripts and related records may be retained according to the server's configured practices and applicable deletion procedures.

### 5.4 Server Settings

Server configurations, including welcome messages and other feature settings, are retained while necessary to provide the configured services.

Stored server information may be deleted following a valid administrator request or when it is no longer necessary.

### 5.5 Command Usage Data

Command usage records may be retained for operational monitoring, troubleshooting, and abuse prevention.

These records are deleted or anonymized when no longer necessary for those purposes.

### 5.6 Economy and Leveling Data

Economy balances, experience points, and related progression information may be retained while the relevant features remain in use.

Eligible records may be deleted following a valid data deletion request.

## 6. Data Sharing and Third-Party Services

Airi interacts with Discord's API to provide its functionality.

The Bot also relies on hosting and database infrastructure, including MongoDB, to operate and store necessary information.

Airi does not share user information or message content with additional third-party services beyond those necessary for its operation, including Discord, its hosting provider, and MongoDB database infrastructure.

Airi does not sell personal information to advertisers or data brokers.

## 7. Data Security

We take reasonable technical and organizational measures to protect stored information against unauthorized access, disclosure, alteration, or loss.

These measures may include:

- Restricted access to database information
- Secure handling of authentication credentials
- Protected database connections
- Access controls for administrative functionality
- Security updates and maintenance

However, no online service or storage system can guarantee absolute security.
